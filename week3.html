Week 3

When comparing the MEI and XML files, there are clear differences with how the elements are displayed. Personally, the XML file is easier to read and navigate, with clearer headings and placements. However the MEI file has more scattered elements and subsectionsl. One comparison of a specific element is how the notes are represented. In the MEI file, they are listed with more details such as the duration of the note, whereas in XML these details are listed under the subsection of the note details. Another example of the difference in elements is the way 'key' is presented. In the MEI file, the key signature is embedded within the code "staffDef", however in the XML file the key is listed completely independently at the beginning of the code. One final example is the difference in how slurs are presented within the code. In the MEI file they are independently placed whereas in the XML file they are within the "line-width" part of the code.
